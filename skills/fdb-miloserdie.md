# Скилл: ФДБ — Милосердие (свод отчётов отделов)

## Порядок работы

Делай строго по шагам, сверху вниз. Не перескакивай.

1. **Прочитай образец**, если он есть среди вложений. Файл с названием «ОБРАЗЕЦ ЗАПОЛНЕНИЯ» — это эталон. Смотри в нём структуру, шапку и оформление ячеек. Иди по нему.
2. **Прочитай все вложения.** Их может быть сколько угодно, и любого типа: `.rtf`, `.docx`, `.odt`, `.xlsx`, `.pdf`, `.zip`, `.txt`, `.csv`, фото. Из каждого выпиши: отдел, какая это часть отчёта, строки мероприятий. Пойми, какой отдел прислал какую часть. Несколько вложений — своди в один общий отчёт. Пустые строки-примеры из образца («Название», «Дата») в отчёт не тащи.
3. **Собери** один отчёт ФДБ по правилам ниже.
4. **Покажи превью** — вызови `report_preview(title=..., text=...)` с тем же текстом, который пойдёт в файл. Пусть заведующая посмотрит глазами.
5. **Сохрани** — если образец есть, через `fill_sample`, если нет — через `save_report`.

Если по ходу работы понадобится другой навык: `skill_list()` покажет список всех, `skill_read(name)` прочитает нужный.

## Описание

Скилл сводит квартальные отчёты отделов (ЦП «Родина», МЦ «Омега», Детский абонемент (АБД), ЦОД и др.) в один отчёт ФДБ по Плану обеспечения жизнедеятельности граждан с ОВЗ НГО.

## Когда применять

Прислали 2–6 отчётов отделов по «Милосердию» — в любом файле, в любом числе, плюс образец. Или пишут: «сведи ФДБ», «отчёт по Милосердию за квартал», «сделай свод по ОВЗ».

## Что нужно от пользователя

- Отчёты отделов — их части формы уже заполнены. Шапка у отчёта отдела такая: «ОТЧЕТ МБУК «Публичная библиотека» НГО <отдел> о выполнении мероприятий...».
- Образец формы («ОБРАЗЕЦ ЗАПОЛНЕНИЯ») — присылают не всегда, но он есть эталон.
- Номер квартала и год.
- Кто составил отчёт. Если не сказали — ставь `Составил: Остапенко И.В.`.

Чего-то не хватает — спроси. Не догадывайся.

## Как собрать отчёт

### Шапка отчёта (дословно)

```
ОТЧЕТ
МБУК «Публичная библиотека» НГО
ФДБ
о выполнении мероприятий по итогам <N> квартала <год> года
Плана по обеспечению жизнедеятельности граждан с ограниченными возможностями здоровья НГО
```

### Таблица (колонки строго так)

| №№ п/п | Наименование мероприятий | Дата исполнения | Ответственный исполнитель | Охват инвалидов мероприятием (человек) | Информация о проведенном мероприятии / привлечение внебюджетных средств |

### Порядок пунктов

1. **Заголовок «1. Обеспечение беспрепятственного доступа инвалидов к информации»** — остаётся всегда, даже если пустой.
2. **Заголовок «2. Создание условий для воспитания и обучения, методические и консультационные мероприятия, переобучение и повышение квалификации»** — остаётся всегда. Ниже только блоки с данными:
   - `2.3. Школа цифровой и финансовой грамотности` (ЦБ ЦОД Иванова И.А.) — данные ЦОД;
   - `2.4 «Покажем. Научим. Подскажем»…` (ФДБ ЦОД Куимова Ю.А.) — в одну ячейку: «1 кв. - 28 занятий», «посещения 1 кв. - 168», темы перечислением с датами;
   - `2.5. «Интернет для жизни и общения»…` (ФДБ ЦОД Шмакова О.С.) — «1 кв. - 28 занятий», «обучено 1 кв.- 14», «посещения 1 кв. - 84».
3. **Заголовок «3. Социокультурная и физическая адаптация различных групп инвалидов через участие в культурно-массовых мероприятиях»** — остаётся всегда. Ниже только подпункты, по которым ЕСТЬ данные. Полный скелет 3.1.1–3.1.18 не выводить. Пустую строку-свод «3.1 Проведение массовых мероприятий» не добавлять.
   - **3.1.2** — блоки по аудиториям:
     - `3.1.2 Мероприятия для пожилых людей (пенсионеров, ветеранов труда, инвалидов) Для Новоуральского комплексного центра социального обслуживания населения (ГАУ СО «НКЦ СОН). Всего мероприятий -N` → строки НКЦ СОН (обычно ЦП «Родина»);
     - `3.1.2 Мероприятия для пожилых людей (пенсионеров, ветеранов труда, инвалидов) 1 кв. - N` → прочие строки пожилых (например, выставка МЦ «Омега»).
   - **3.1.11** ГКОУ СО «Новоуральская школа №1» (бывшая «НСКОШ №50») — Детский абонемент;
   - **3.1.12** ГКОУ СО «Новоуральская школа №2» (бывшая «НСКОШ №59») — строки Детского абонемента И МЦ «Омега» вместе, в одном блоке. У Омеги в исходнике может стоять 3.1.13 — перенумеруй в 3.1.12.
   - **3.1.13** Мероприятия для воспитанников ГБУ СОН СО «СРЦН» г. Новоуральска — ЦОД;
   - **3.1.14** Мероприятия для молодёжного клуба «Родник» (Клуб по месту жительства «Орленок») — МЦ «Омега»;
   - другие подпункты (3.1.8 «Кедр», 3.1.9 садики, 3.1.10 интернат №53, 3.1.15+, 4, 5, 6) — только если у отделов есть по ним данные, с номерами из присланной формы-эталона.
4. **Разделы 4–7 в итог не выводить, если по ним нет данных.** В реальных отчётах их обычно нет.
5. Последняя строка: `Составил: Остапенко И.В.` (или ФИО, которое назовёт пользователь).

### Инструменты

- `report_preview(title, text)` — показать черновик на экране. Вызывай до сохранения.
- `fill_sample(sample_path, title, markdown, replacements)` — вписать строки прямо в образец. Шрифты, размеры и таблицы останутся как в оригинале. `replacements` — список пар `[[текст из шапки образца, нужный текст], …]`. Это главный способ: **если образец есть, сохраняй только через `fill_sample`**.
- `save_report(title, markdown, format)` — сохранить отдельным файлом. `format`: `"rtf"`, `"docx"`, `"odt"` или `"md"`. Бери тот формат, в котором прислан образец, а если образца нет — `"rtf"`.
- `skill_list()`, `skill_read(name)` — список навыков и чтение навыка.

Название файла: `ФДБ Милосердие — <N> квартал <год>`.

## Правила

1. Строки мероприятий переноси дословно: название, дата, ответственный, охват, информация. Ничего не переписывай своими словами. Пустые ячейки оставляй пустыми.
2. Блок-заголовок подпункта: `<номер> <название> Всего мероприятий - <кол-во>, охват <сумма>` — либо как «Всего мероприятий -N <сумма>», как в драфте. Внутри блока сначала строка-заголовок, потом строки-мероприятия.
3. «Всего мероприятий» — это количество ПРОВЕДЁННЫХ мероприятий. Учитывай цифры в названии: если строка «3 мероприятия» — считай 3. Охват — обычная сумма чисел строк. Для «36 (12-12-12)» сумма равна 36.
4. Опечатки правь только очевидные: «ФБД» → «ФДБ», даты вида «05.022026» → «05.02.2026», «19.03. 2026» → «19.03.2026».
5. Если номер пункта в отчёте отдела не совпадает с формой-эталоном — определи раздел по смыслу и поставь номер по правилам выше. Для школ, СРЦН и «Родника» номера фиксированные: 3.1.11–3.1.14.
6. **Цифры — только из исходников.** Не выдумывай ни одной цифры: ни количество мероприятий, ни охват, ни дат, ни квартала. Не хватает данных — спроси пользователя, а не догадайся.
7. Никаких додумываний и «красивых» формулировок. Отчёт собирают отделы, ты только сводишь.

## Проверка перед сдачей

- Собраны все отделы из задания. Сверь шапки исходников.
- Шапка итога верная: «ФДБ», нужный квартал и год.
- Каждый блок 3.1.x — только с данными. Номера по правилам: 3.1.2 / 3.1.11 / 3.1.12 / 3.1.13 / 3.1.14.
- Школа №2 собрана из всех отделов в один блок. НКЦ СОН — в 3.1.2 отдельным блоком.
- Все суммы пересчитаны сложением по строкам, а не взяты из шапки.
- Номера пунктов сверены с правилами и с формой-эталоном.
- Ни одна строка не потеряна и не задвоена. Пересчитай строки отчёта и строки всех исходников — числа должны совпасть.
- Превью показано (`report_preview`), файл сохранён, путь назван в ответе.

## Если что-то непонятно

Расхождения не молчат. В конце ответа пользователю, отдельным коротким списком и ВНЕ отчёта, перечисли:

- какие разделы или подпункты пропали, потому что данных не было;
- где номер пункта в отчёте отдела не совпал с номером по правилам и почему ты поставил именно такой;
- какие цифры выглядят спорно или не сходятся между отделами;
- чего не хватает: нет образца, не указан квартал, не указан составитель, вложение не читается.

Решение принимает пользователь. Ничего не правь в отчёте по своему усмотрению — спрашивай.
