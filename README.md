# DB Bot Lite

Настольный помощник для одного человека. Работает на своём компьютере, в интернет ходит
только за ответом модели. Сделан для заведующей детской библиотеки: пишет отчёты,
считает, помогает с идеями и с поиском свежей информации.

## Что это умеет

- **Сам пишет отчёты.** Прикрепляете файлы отделов — получаете один сводный отчёт.
- **Работает с любыми файлами.** `.rtf`, `.docx`, `.odt`, `.xlsx`, `.pdf`, `.zip`, фото —
  всё, что можно открыть и прочитать.
- **Знает 10 отчётных скиллов** библиотеки Новоуральска: ФДБ «Милосердие», «Подросток»,
  «Безопасность», «Чтение», «АНК», «Экстремизм», «Новоуральская семья»,
  «Общественное здоровье», «Территория здоровья», «Значимые события».
- **Заполняет образец, а не придумывает.** Если прислали бланк-эталон, бот впишет данные
  прямо в него — шрифты и таблицы останутся как в оригинале.
- **Приносит свежую информацию** по запросу и предлагает идеи.
- **Сохраняет и печатает.** Кнопка «Сохранить» и отдельная кнопка «Печать».

## Чего приложение не делает

- Не собирает ваши данные и никуда не отправляет. Телеметрии нет вообще.
- Не требует аккаунта и пароля. У него один пользователь.
- Не работает в облаке и не запускает виртуальные машины. Всё — на этом компьютере.

## Требования

Windows 10 или новее, 8 ГБ оперативной памяти, около 2 ГБ свободного места на диске.
Видеокарта подойдёт любая — играть в игры приложение не собирается.

## Установка

1. Скачайте `DB Bot Setup.exe` из раздела Releases.
2. Запустите и установите.
3. При первом запуске введите ключ DeepSeek.

## Обновления

Обновление приезжает само. Когда вышла новая версия, приложение предложит обновиться —
достаточно нажать «Обновить» и подождать пару минут. Устанавливать ничего не нужно.

## Для разработчиков

Нужен Node.js 26 и npm.

```powershell
npm ci --no-audit --no-fund --ignore-scripts   # зависимости
npm run frontend:build                         # интерфейс
npm run build                                  # приложение целиком -> .build/app.asar
npm test                                       # проверки
npm run package:windows                        # .exe в dist\
```

Всё собирается из исходников: `frontend/` — интерфейс, `source/` — процессы,
`skills/` — отчётные скиллы. Никаких готовых чужих сборок.

Прочитай [AGENTS.md](AGENTS.md) до того, как что-то менять: там записаны ловушки,
которые в этом проекте уже стоили времени.

## Состав

| Папка | Что внутри |

| `frontend/` | Интерфейс на React + TypeScript |
