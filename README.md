# Grok Bot Lite

Простое десктоп-приложение: выбираете папку с проектами — и просите ИИ помочь
обычными словами («сделай красивее», «добавь кнопку», «почини ошибку»).

## Для пользователя (5 шагов)

1. Установите приложение файлом `*-setup.exe` и запустите его двойным кликом.
2. На экране «Мои проекты» нажмите «Выбрать папку» и укажите, где лежат проекты.
3. Откройте нужный проект кнопкой «Открыть».
4. Напишите внизу, что нужно сделать, и нажмите «Отправить».
5. Если что-то пошло не так — нажмите «Откатить», всё вернётся как было.

> На компьютере-сервере должен работать AI-сервис OmniRoute: откройте порт
> `20128` в брандмауэре и задайте компьютеру постоянный (статический) IP-адрес.

## Для разработчика

Стек: Tauri 2 + React 18 + TypeScript + Vite. Пакетный менеджер — `pnpm`.

```bash
pnpm install        # зависимости
pnpm tauri dev      # запуск в режиме разработки
pnpm tauri build    # релизная сборка → src-tauri/target/release/bundle/nsis/*.exe
```

Настройки AI зашиваются при сборке: скопируйте `.env.example` в `.env`
(файл не коммитится) и подставьте `VITE_AI_API_KEY`. Значения читаются во
фронтенде через `import.meta.env` (`src/config.ts`) и в Rust через `build.rs`.

Структура `src/`:

- `screens/` — три экрана: Мои проекты, Чат, Настройки
- `components/` — общие компоненты (сайдбар и др.)
- `services/` — обёртки над `invoke` (`tauri.ts`) и клиент AI (`ai.ts`)
- `stores/` — zustand-состояние
- `hooks/` — react-хуки
- `styles/` — глобальные стили (тёмная тема, фиолетовый акцент)

Команды Rust (`src-tauri/src/commands.rs`): `scan_projects`, `project_status`,
`read_file`, `apply_changes`, `rollback`, `git_is_repo`.
